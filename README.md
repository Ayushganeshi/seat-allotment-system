# seat-allotment-system
This project takes student data as input from an Excel sheet and automatically generates room-wise PDF seat allotment lists. The system follows constraints such as ensuring that no two students from the same branch are seated next to each other. Seat allocation is performed using registration numbers to maintain order and fairness.
Scope of improvement: We will work on a common interface for both the students and admin for posting and receiving details of examination and seating arrangements.
